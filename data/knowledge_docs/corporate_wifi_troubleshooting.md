# Troubleshoot a corporate Wi-Fi connection

Use these basic checks when a managed device cannot connect to the expected corporate wireless network.

## Steps

1. Confirm Wi-Fi is enabled and airplane mode is off.
2. Select the exact corporate network name provided by IT. Avoid similarly named or open networks.
3. Move closer to an approved access point and retry once. If other trusted devices are available, check whether they can connect.
4. If your organization provides a Wi-Fi setup guide, follow it to rejoin the network. Do not install a certificate or profile from an unverified prompt or website.
5. Restart the device if practical, then try connecting again.
6. Record the displayed message and whether the device receives a network connection.

## Security reminders

Do not bypass certificate warnings, share the corporate Wi-Fi password publicly, or use an unknown network to access company systems. Use the organization's approved guest network only when authorized.

## Escalate to IT

Contact IT if the network is missing, authentication repeatedly fails, a certificate warning appears, or several users in the same location are affected. Include the building or area, device type, network name, error text, and time observed. Never send passwords or private network keys in a ticket.
