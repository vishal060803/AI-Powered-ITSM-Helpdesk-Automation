# Troubleshoot access to a business application

Use these checks when a work application rejects a sign-in or reports that access is not authorized.

## Steps

1. Confirm you are using the organization's official application URL and the correct work account, especially if you use multiple accounts.
2. Check the error message and confirm the device date and time are correct.
3. If the application uses single sign-on, start from the approved company portal and complete MFA only for a sign-in you initiated.
4. Retry in a supported browser. If allowed by company policy, use a private window to check whether a stale browser session is involved. Do not share browser session links.
5. Confirm whether the application requires a role, group membership, license, or manager approval. Submit an access request through the approved process if needed.

## Security reminders

Never approve an unexpected MFA prompt or send passwords, verification codes, cookies, or session tokens to anyone. Do not try to gain access through another employee's account.

## Escalate to IT

Contact the application support team if access is denied after approval, the sign-in loops, or the service reports an outage. Include the official app name, error text, time, device and browser, and any request reference. Exclude passwords, MFA codes, and session tokens from screenshots or tickets.
