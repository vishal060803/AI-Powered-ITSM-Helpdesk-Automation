# Basic checks for a slow work laptop

These low-risk checks can help identify common causes of poor performance on a managed work device.

## Steps

1. Save your work and restart the laptop if it has been running for a long time.
2. Close applications and browser tabs you recognize but are not using. Do not terminate unfamiliar security or management processes.
3. Check the operating system's built-in task monitor for an application using unusually high CPU or memory. Note the application name; do not disable endpoint protection.
4. Check available storage in system settings. Use only organization-approved cleanup tools, and do not delete work files to free space.
5. Install pending updates through the normal company update process and restart when prompted.
6. Make sure vents are not blocked. If the device is unusually hot, noisy, or shuts down, stop intensive work and contact IT.

## Security reminders

Do not install third-party cleanup or driver tools, change security settings, or remove managed software to improve speed.

## Escalate to IT

Contact IT if slowness persists after a restart, affects several managed applications, or is accompanied by overheating, disk errors, crashes, or unusual security alerts. Include when the issue began, affected applications, recent changes, and any error messages. Do not attach confidential files unless requested through an approved support channel.
