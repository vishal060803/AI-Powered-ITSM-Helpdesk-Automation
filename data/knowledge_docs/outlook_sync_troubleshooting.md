# Troubleshoot Outlook email synchronization

Use these checks when Outlook is not sending, receiving, or updating messages. Do not delete mailbox data or change account settings unless IT instructs you to.

## Steps

1. Confirm the device is online and that other approved sites or applications work.
2. Check the organization's service-status page, if available, for an email outage or scheduled maintenance.
3. In Outlook, confirm the correct work account is selected and that the application is not in an offline or disconnected mode.
4. Close and reopen Outlook once. If convenient, compare with the organization's approved webmail page to determine whether the issue is limited to the desktop app.
5. Install Outlook updates through the normal company update or software process, then restart the application.
6. Note whether the issue affects all folders or only a particular mailbox or message.

## Security reminders

Do not forward sensitive messages to a personal account to test delivery. Do not share passwords, MFA codes, or mail-session links with support.

## Escalate to IT

Contact IT if synchronization remains delayed, Outlook repeatedly requests credentials, messages are missing, or webmail and desktop results differ. Include the error text, approximate time of the last successful sync, affected device, and whether other users are affected. Do not remove an Outlook profile or local data file unless directed by IT.
