# Request or install approved work software

Install work software only through the organization's approved software catalog or IT process. Approval and licensing requirements depend on the software and role.

## Steps

1. Search the company software catalog for the application and verify the publisher and supported version.
2. Review any eligibility, manager approval, or license requirements shown in the catalog.
3. If self-service installation is offered, start it from the catalog and follow the managed installer prompts.
4. If the application is not listed or requires approval, submit a software request with the business need and device details requested by the form.
5. Restart the application or device if the installer requests it, then confirm the application opens as expected.

## Security reminders

Do not download installers from unofficial websites, use a personal license for company work, or bypass administrator controls. Do not disable security tools to complete an installation.

## Escalate to IT

Contact the software support team if the catalog reports an installation failure, the application is missing after a successful request, or a license or compatibility error appears. Include the application name, catalog version, device type, request reference, and error text. Do not share license keys or administrator credentials.
